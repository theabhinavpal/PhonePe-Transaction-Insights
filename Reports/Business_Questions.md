# Business Questions (75)

The analytical scope of the project, phrased as business questions. Each maps
to one or more queries in `database/queries.sql` and/or a dashboard view.

## A. Volume, Value & KPIs
1. What is the total transaction value across India for the full period?
2. What is the total transaction volume (count) across India?
3. What is the overall average transaction value (ticket size)?
4. How many transactions and how much value were processed per year?
5. What is the value processed in the most recent quarter?
6. How many states/UTs, years and quarters does the dataset cover?
7. What is the average number of transactions per registered user?
8. What is the national quarter-over-quarter value trend?
9. What is the 4-quarter moving average of national value?
10. What is the cumulative (running-total) value over time?

## B. Growth & Trend
11. What is the year-over-year value growth for each year?
12. What is the compound annual growth rate (CAGR) of value?
13. Which quarter has historically been the strongest?
14. What is the average Q4-vs-Q1 seasonal uplift?
15. Which quarter is the annual peak within each year?
16. What share of all-time value does each year contribute?
17. How fast are registered users growing year over year?
18. Is engagement (app opens per user) rising or falling over time?
19. How does value growth compare with user growth?
20. Which year saw the highest incremental value?

## C. State Analysis
21. Which are the top 10 states by transaction value?
22. Which are the bottom 10 states by transaction value?
23. What is each state's market share of national value?
24. How do states rank by value (with ties handled)?
25. Which states are above the national average state value?
26. What is the cumulative value share as we walk states largest-to-smallest (Pareto)?
27. Which state leads in the most recent quarter?
28. Which state has the highest average ticket size?
29. Which single state champions each region?
30. Which states grew fastest from the first to the latest year?

## D. Regional Analysis
31. What share of value comes from each region?
32. Which region has the highest average ticket size?
33. Which category leads in each region?
34. How does regional share change over time?
35. Which region is growing fastest?

## E. Category Analysis
36. What is the value and volume of each payment category?
37. What is each category's share of total value?
38. What is the average ticket size per category?
39. How has category value-share shifted from the first to the latest year?
40. Which category is growing fastest by YoY value?
41. Which categories contribute above one-fifth of value?
42. What is the category value trend by year (for a stacked-area chart)?
43. Which category dominates transaction volume vs value?
44. How does category mix differ across the top states?
45. What is the merchant-to-P2P value ratio over time?

## F. District Analysis
46. Which are the top 15 districts by value nationwide?
47. What are the top 3 districts within each state?
48. What share of value do the top 20% of districts hold?
49. Which districts have the highest average ticket size?
50. How many distinct districts have transaction activity?
51. Which districts are growing fastest?
52. Which district leads each state in the latest quarter?
53. How concentrated is value at district level (Pareto)?
54. Which districts punch above their weight (high value, modest user base)?
55. What is the value gap between the top and median district?

## G. Pincode Analysis
56. Which are the top 20 pincodes by value nationwide?
57. What are the top 5 pincodes within each state?
58. How concentrated is value in the top 50 pincodes?
59. Which pincodes have the most registered users?
60. Do user hotspots coincide with value hotspots?

## H. User & Engagement
61. How many registered users and app opens in the latest quarter?
62. Which states have the most registered users?
63. What is the device-brand market share of the user base?
64. Which states have the highest app-opens-per-user (engagement)?
65. Which states have the most transactions per registered user?
66. What is the national registered-user QoQ growth?
67. Which device brand is gaining/losing share?
68. How does engagement vary by region?
69. What is the ratio of app opens to transactions?
70. Which states are "sign-up heavy" but "engagement light"?

## I. Insurance Analysis
71. What is the total insurance premium and policy count since launch?
72. Which states lead in insurance premium?
73. What is insurance penetration (premium as a share of transaction value) by state?
74. How fast is insurance premium growing year over year?
75. Which districts and regions have the highest insurance uptake and average premium?
